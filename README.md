# Site Institucional — Advocacia

Website institucional desenvolvido para apresentar a atuação profissional da advogada **Karen Priscila da Rosa Dainez**, com foco na advocacia criminalista.

O projeto foi concebido para transmitir profissionalismo, confiança e sofisticação por meio de uma identidade visual elegante, navegação intuitiva e experiência responsiva.

## ✨ Sobre o projeto

A plataforma apresenta informações profissionais, áreas de atuação jurídica e canais de contato, proporcionando aos visitantes uma experiência digital clara e objetiva.

O design combina tons neutros, detalhes dourados e tipografia sofisticada, reforçando a identidade visual institucional.

## 🎯 Funcionalidades

- Apresentação profissional e institucional.
- Seção de áreas de atuação com cards interativos.
- Modais com informações específicas sobre cada especialidade.
- Seção de atendimento urgente 24 horas.
- Integração com WhatsApp para contato direto.
- Barra dourada de progresso de leitura.
- Menu de navegação fixo com efeito de transparência.
- Menu responsivo para dispositivos móveis.
- Animações suaves e efeitos de interação.
- Efeitos de entrada de conteúdo durante a navegação.
- Botão flutuante de WhatsApp.
- Layout adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias

- **HTML5:** estruturação semântica e organização do conteúdo.
- **CSS3:** identidade visual, responsividade, transições e animações.
- **JavaScript:** interatividade, navegação, modais e funcionalidades dinâmicas.
- **Tailwind CSS:** recursos de estilização.
- **Lucide:** biblioteca de ícones.
- **Google Fonts:** composição tipográfica.

## 🎨 Identidade visual

A identidade visual foi desenvolvida com uma proposta sofisticada e minimalista, utilizando uma combinação de tons creme, espresso e dourado.

## 📱 Experiência e responsividade

A interface foi projetada para oferecer uma experiência consistente em computadores, notebooks, tablets e smartphones.

A navegação se adapta aos diferentes dispositivos, com menu mobile, elementos reorganizados e interações otimizadas para telas menores.

## ✨ Destaques técnicos

- Barra de progresso de leitura calculada conforme a rolagem da página.
- Navbar fixa com efeito glassmorphism.
- Animações utilizando Intersection Observer.
- Efeitos de parallax e transições.
- Modais com suporte a teclado e interação externa.
- Controle centralizado dos links e mensagens do WhatsApp.
- Cuidados com acessibilidade e comportamento responsivo.
